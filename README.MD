# Hospital Readmission Risk Predictor

A machine learning system that predicts 30-day hospital readmission risk for diabetic patients. Built as a final project for CSC 44700: Machine Learning.

## Overview

Hospital readmissions within 30 days are a major indicator of care quality and a significant cost driver in healthcare. This project trains a logistic regression classifier on the [Diabetes 130-US Hospitals Dataset](https://archive.ics.uci.edu/dataset/296/diabetes+130-us+hospitals+for+years+1999-2008) (101,766 records) and exposes predictions through a Flask API and a browser-based frontend.

## Setup

### 1. Install dependencies

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Train the model

Run this once to generate `model_pipeline.pkl` and `feature_importance.json`:

```bash
python backend/train_model.py
```

### 3. Start the Flask backend

```bash
python backend/app.py
```

The API will be available at `http://127.0.0.1:5000`.

### 4. Open the frontend

Open `frontend/index.html` directly in a browser. No build step required.

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/predict` | Returns readmission prediction and risk probability |
| GET | `/feature-importance` | Returns logistic regression coefficients sorted by magnitude |

### Example `/predict` request

```json
{
  "age": "[70-80)",
  "gender": "Female",
  "insulin": "No",
  "time_in_hospital": 5,
  "num_medications": 18,
  "number_inpatient": 2,
  "number_emergency": 0
}
```

### Example response

```json
{
  "prediction": 1,
  "probability": 0.5888
}
```

## Model

- **Algorithm:** Logistic Regression with `class_weight="balanced"`
- **Features:** age, gender, insulin status, days in hospital, number of medications, prior inpatient visits, prior emergency visits
- **Preprocessing:** OneHotEncoder for categorical features, StandardScaler for numeric features, wrapped in a single sklearn `Pipeline`
- **Train/test split:** 80/20, stratified by class

### Performance

| | Precision | Recall | F1 |
|---|---|---|---|
| Not Readmitted (0) | 0.92 | 0.71 | 0.80 |
| Readmitted within 30 days (1) | 0.17 | 0.48 | 0.25 |
| **Overall Accuracy** | | | **0.68** |

The dataset is heavily imbalanced (88.8% not readmitted). Recall on the readmitted class (0.48) is the primary metric of interest, as missing a high-risk patient is more costly than a false alarm. Logistic regression with balanced weights outperformed Random Forest and Gradient Boosting on this metric, which both defaulted to predicting the majority class.

### Top predictors of readmission risk

| Feature | Direction |
|---|---|
| Prior inpatient visits | Increases risk |
| Age 70–90 | Increases risk |
| Longer hospital stay | Increases risk |
| No insulin / Steady insulin | Decreases risk |
| Younger age (10–20) | Decreases risk |

## Dataset

**Diabetes 130-US Hospitals for Years 1999-2008**
- Source: UCI Machine Learning Repository
- 101,766 patient encounters across 130 US hospitals
- 50 features including demographics, diagnoses, medications, and lab results
- Target: readmission within 30 days (binary, 11.2% positive rate)
